# Life Admin

A mobile-first PWA for logging the dates you'd otherwise forget — insurance
renewals, tax deadlines, MOTs, birthdays, anniversaries — with push reminders
a configurable number of days before each event.

Single-user. No accounts, no login. Supabase provides the Postgres store and is
accessed server-side only.

## Stack

- **Next.js 15** (App Router) + **TypeScript** + **Tailwind CSS**
- **Supabase Postgres** (service-role key, server-side only)
- **Web Push** (VAPID) via a service worker
- **Vitest** for unit tests on recurrence logic

## Prerequisites

- Node.js 20+
- A Supabase project (free tier is fine)
- A mailto address for VAPID

## Setup

```bash
npm install
cp .env.example .env.local
```

1. In Supabase, open the SQL editor and run `supabase/migrations/0001_init.sql`.
2. Generate VAPID keys:
   ```bash
   npx web-push generate-vapid-keys
   ```
3. Fill in `.env.local`:
   - `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`
   - `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT` (`mailto:you@…`)
   - `NEXT_PUBLIC_VAPID_PUBLIC_KEY` (same as `VAPID_PUBLIC_KEY`)
   - `CRON_SECRET` (any random string)

## Run

```bash
npm run dev
```

Open `http://localhost:3000` on desktop, or the network URL Next.js prints on
your phone's browser. Tap **Enable reminders** to subscribe to push, then add
some events.

To install as a PWA on iOS: open in Safari → Share → **Add to Home Screen**.
Note that iOS requires the home-screen-installed variant before push
notifications will work.

## Testing reminders locally

```bash
curl -H "x-cron-secret: $CRON_SECRET" \
  http://localhost:3000/api/cron/reminders
```

You'll see `{ "checked": N, "sent": M }`. A push should arrive on any device
that has subscribed, *if* any event's next occurrence is exactly one of its
`reminder_days_before` values away.

## Tests

```bash
npm run test         # vitest (recurrence logic)
npm run typecheck    # tsc --noEmit
```

## Deploy (Vercel)

1. Push this repo, import into Vercel.
2. Add the env vars from `.env.local` to the Vercel project.
3. `vercel.json` registers a daily cron at 09:00 UTC hitting
   `/api/cron/reminders`. Vercel Cron sends
   `Authorization: Bearer $CRON_SECRET`, which the handler accepts.

## Project layout

```
app/
  layout.tsx            PWA shell, service-worker registrar
  page.tsx              upcoming events grouped by bucket
  events/new            create form
  events/[id]           edit/delete form
  categories            manage categories
  api/
    events              GET/POST list + create
    events/[id]         GET/PATCH/DELETE
    categories          GET/POST
    notifications/subscribe  POST store PushSubscription
    cron/reminders      GET send pushes (protected by CRON_SECRET)
components/             client components (forms, buttons)
lib/
  supabase.ts           server-side Supabase client + types
  recurrence.ts         next-occurrence + bucketing helpers
  webpush.ts            VAPID-configured wrapper around web-push
public/
  manifest.webmanifest  PWA manifest
  sw.js                 service worker (shell cache + push)
  icon-*.png            generated by `scripts/gen-icons.mjs`
supabase/migrations/    schema + seed categories
```
