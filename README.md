# Life Admin

A mobile-first PWA for logging the dates you'd otherwise forget — insurance
renewals, tax deadlines, MOTs, birthdays, anniversaries — grouped by how soon
they're coming up, with day-of-month-aware yearly and monthly recurrence.

Single-user. Data lives in the browser's `localStorage` — no backend, no
accounts, no setup.

## Stack

- **Next.js 15** (App Router) + **TypeScript** + **Tailwind CSS**
- **lucide-react** icons, **Inter** font via `next/font`
- **Vitest** unit tests for recurrence logic

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. Sample events and default categories seed
automatically on first load.

To reset the data: open DevTools → Application → Local Storage → remove the
`life-admin.v1` key, then reload.

## Tests

```bash
npm run test         # vitest (recurrence logic)
npm run typecheck    # tsc --noEmit
```

## Deploy (Vercel)

Push the branch, import into Vercel, done — no env vars required.

## Project layout

```
app/
  layout.tsx            PWA shell, Inter font
  page.tsx              upcoming events grouped by bucket
  events/new            create form
  events/[id]           edit/delete form
  categories            manage categories
components/
  EventList.tsx         bucketed list + card
  EventForm.tsx         create/edit form
  CategoryManager.tsx   add/delete categories
lib/
  types.ts              Category, EventRecord, Recurrence
  store.ts              localStorage-backed store (React hook)
  recurrence.ts         next-occurrence + bucketing helpers
public/
  manifest.webmanifest  PWA manifest
  icon-*.png            generated by `scripts/gen-icons.mjs`
```

## Roadmap

- Bring back push/email reminders via a proper backend (Supabase + Vercel Cron,
  or similar). The UI hooks are gone for now — localStorage can't be read by a
  server cron, so reminders fire only while the app is open.
- Flexible recurrence (every N weeks, last weekday of month, etc.).
- Optional cloud sync across devices.
- Export / import JSON.
